# 无缝长图

原生微信小程序：按顺序选择 2–20 张竖向连续截图，在手机本地识别重复区域、微调接缝并导出一张 PNG 长图。

## 当前能力

- 图片不上传、不创建账号、不接入分析 SDK。
- 自动识别相邻截图重叠，固定顶部栏仅保留第一张，固定底部栏仅保留最后一张。
- 低置信度或低纹理内容转入手动接缝，不静默猜测。
- 最终结果限制为 1600 万像素且高度不超过 32767px；超出时自动等比缩小，导出失败最多再降尺寸重试 3 次。
- 支持固定首页卡片转发给好友或朋友圈、保存相册、重新拼接和任务取消。

## 打开与运行

1. 安装依赖：`npm install`
2. 执行检查：`npm run check`
3. 使用微信开发者工具导入本目录，首次预览可使用测试号；正式发布前将 `project.config.json` 的 `appid` 替换为已注册小程序 AppID。
4. 基础库最低版本为 2.32.3；真机调试时分别验证 iOS 与 Android。

## 目录

- `miniprogram/pages/index`：单页状态机与全部交互界面。
- `miniprogram/workers`：可独立测试的重叠识别算法及 Worker 协议。
- `miniprogram/services`：分析 Canvas、拼接计划与 PNG 导出。
- `tests`：Node 内置测试运行的算法与取消协议测试。

## 当前边界

首版只保证同一设备、同一方向的竖向连续截图。横向拼接、明显横向错位、缩放变化、透视变化和云端历史记录不在范围内。旋转或宽高方向不一致的图片应先在系统相册中统一方向。
