# 阶段1：首版实现与正式发布准备

完成“青缝长图拼接”原生微信小程序首版：支持2—20张连续截图选择和排序、Worker自动识别重叠、低置信度手动接缝、长图预览、PNG导出、保存相册和分享。修复预览按钮不可见与真机导出黑块问题，模拟器和真机两图测试正常；自动测试覆盖不同重叠比例、固定栏、低纹理、无重叠、不同宽度、旋转、20张输入和取消任务。

项目由接口测试号切换至正式小程序账号，账号改名为“青缝长图拼接”，简称及头像已更新；正式AppID已写入配置。用户完成图片处理服务类目、隐私保护指引和微信认证相关操作，并提交小程序备案，当前等待审核。首页标题已统一为“青缝长图”，本地版本升级至0.1.1，`npm run check`与14项测试通过，未发现网络请求。

已知问题：自动上传0.1.1多次超时且没有回执，需在后台核对是否手动上传；提交审核前还需在全新授权状态验证平台隐私确认、选图和保存相册。备案通过后才能继续版本审核、发布和开启搜索。
