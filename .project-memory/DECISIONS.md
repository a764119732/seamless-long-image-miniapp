# 长期决策

- 产品采用原生微信小程序、TypeScript、WXML、WXSS、Canvas 2D和Worker，不接后端。
- 原图和结果不上传服务器；图片仅在本次任务中本地处理。
- 正式账号名称为“青缝长图拼接”，页面品牌标题为“青缝长图”。
- 正式分发目标是审核发布后允许微信搜索，不依赖体验成员白名单。
- 服务类目以图片处理/实用工具为准；备案不涉及新闻、出版、教育、影视、医疗等前置审批业务。
- 隐私声明仅覆盖用户选择的照片或视频信息及相册写入权限，不使用第三方SDK。
- 固定分享只允许预设首页卡片，不读取或分享用户原图、拼接结果。
- 本机选图与本地拼接不视为产品内的用户内容发布场景；遇到UGC误判优先提交人工复核，不为过审直接引入后端、内容上传或内容安全API。
- 线上稳定版与开发审核版分开描述：0.1.3已上线，0.1.5未通过审核前不得宣称已发布。
