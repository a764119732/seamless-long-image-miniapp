2. 打开“通知中心”，进入 2026-07-28 20:37:08 的代码发布审核结果。

## 申诉正文

小程序名称：青缝长图拼接

申诉版本：0.1.4

申诉事项：申请人工复核“截图功能内容安全”审核结论

本小程序是纯本地图片处理工具，不提供用户内容发布场景。用户主动选择的连续截图仅在设备本地完成重叠识别、拼接、预览和保存，不上传开发者服务器；小程序没有账号、社区、评论、投稿、公开内容展示或向其他用户发布截图的功能。

0.1.4 新增的分享能力仅为微信标准的小程序首页卡片，分享内容由开发者固定配置：

1. 分享标题固定为“青缝长图拼接｜连续截图自动去重复叠”；
2. 分享路径固定为 `/pages/index/index`；
3. 分享封面固定为开发者预置的 `/assets/share-card.png`；
4. 分享参数不读取用户选择的原图、临时文件或拼接结果；
5. 代码未调用 `wx.showShareImageMenu`，也没有 `wx.request`、`wx.uploadFile` 或云端图片上传逻辑。

因此，本版本的分享对象是固定的小程序首页卡片，不是用户截图或拼接结果，不存在用户发布图片内容的场景。针对审核意见中要求接入内容安全 API 的部分，恳请平台按上述实际功能进行人工复核，并确认固定首页卡片分享是否被平台认定为“用户发布截图内容”。如仍需整改，也请明确适用的具体规则、需审核的内容对象和接口范围，以便开发者准确处理。

感谢复核。
