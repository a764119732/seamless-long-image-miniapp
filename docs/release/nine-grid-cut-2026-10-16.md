# 一图切九张

## 已确认需求

- 替换原“2–9 张照片拼成一张”的功能；选择 1 张图片切成 9 张独立图片。
- 用户确认完整保留原图，横竖图居中补白成正方形后切分。
- 普通 2–99 张长图拼接保持免费；一次激励视频解锁本次全部九张导出，无广告时免费兜底，保存及失败重试不重复要求观看。

## 实现

- 复用原选图、隐私授权、Canvas、广告及任务状态流程。仅选 1 张时显示“九宫格切图 · 一张切九张”。
- 免费预览按从左到右、从上到下显示 1–9 分格标记。标记仅在界面显示，不写入导出图片。
- 组合正方形最大 3240 × 3240，每张切片最大 1080 × 1080。统一整数边长确保无缺口，原图等比缩放并补白，不裁去内容。
- 九张 PNG 串行导出，保持源图直到快照结束。中途失败或任务取消时清理本轮已生成的临时切片；导出最多三次、逐次缩小，失败后保留本次广告解锁权益。
- 保存按 1–9 串行执行；显示保存进度，重复点击不启动并行保存，失败只重试未成功的部分。用户仍应在朋友圈按预览顺序选图，相册显示顺序受设备影响。
- 图片处理不上传服务器，不增加 SDK、积分、充值或付费。

## 验证

- `npm run check`：TypeScript 及 58 项测试通过。包括横图、竖图、正方形、非整除尺寸、九张独立文件、原图完整范围及等比绘制、取消/失败清理、部分保存拒权后续存，以及原有拼接与广告回归。
- 微信开发者工具官方 CLI 预览已编译成功，最终包大小 108010 字节（105.5 KB），二维码为 `.tools/preview-nine-cut/preview.png`。

- 0.1.8 仍是旧版“多张拼一张”；新切图版本应在手机确认后上传为 0.1.9，并核对后台版本状态再提审。

## 新版审核说明草稿（上传新版后使用）

支持2–99张图片上下/左右拼接、截图去重和完整照片拼接；新增九宫格切图：选1张图片，完整保留并补白成正方形，切成9张独立图片，支持全部保存到相册。图片仅在本机处理、不上传，无需登录，无作品发布入口。普通拼接保存免费；切图预览免费，用户主动观看一次激励视频解锁本次九张导出，无可用广告时本次免费，导出失败重试及保存不重复看广告。不含积分充值或付费。

## 隐私用途建议（保存后台后另行确认）

- 相册仅写入：用户主动点击保存后，将生成的长图或九宫格切图保存到手机相册。
- 选中的照片或视频信息：用户从手机相册选择图片，在本机进行截图去重、完整照片拼接、九宫格切图及预览；原图和结果不上传服务器。
