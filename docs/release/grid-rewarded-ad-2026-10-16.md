# 宫格拼图与激励视频接入

## 本次实现

- 原有 2–99 张拼接、截图去重、完整拼图、保存相册保持免费。
- 新增“宫格拼图”：2–9 张照片按顺序排成一张白底 PNG，等比缩放、完整保留照片，空白处留白。
- 宫格预览不请求广告。用户主动点击“观看广告并导出”后，才请求微信激励视频。
- 完整观看解锁本次任务；提前关闭保留预览，仍可返回普通拼接。
- 广告接口不存在、无填充、加载或展示失败时，本次免费导出；加载 15 秒未返回也执行兜底。
- 导出失败后可返回预览重试，保留本次解锁状态；保存相册不再次请求广告。
- 本阶段不增加积分、充值、付费、账号或图片上传。

- 代码仅从相册选择图片（`chooseMedia` 的 `mediaType: ["image"]`、`sourceType: ["album"]`），用户主动点击保存时调用 `saveImageToPhotosAlbum`；建议将两项用途更新如下。

**相册（仅写入）用途：**

用户主动点击保存后，将生成的长图或宫格拼图保存到手机相册。

**选中的照片或视频信息用途：**

用户从手机相册选择图片，在本机进行截图去重、完整照片拼接、宫格拼图及预览；原图和结果不上传服务器。

- 本项目未引入独立第三方 SDK，广告通过微信原生 `wx.createRewardedVideoAd` 调用；不应编造第三方 SDK 或广告服务收集的信息类型。微信广告服务需要联网，不能将“图片不上传”表述为“小程序完全不联网”。
- 官方依据：[腾讯云隐私保护指引适配说明](https://cloud.tencent.com/document/product/1301/97930)，声明内容应对应实际使用的隐私接口。微信开发文档本次未能直接打开，未独立确认官方原生广告是否存在额外后台声明要求；如后台出现广告相关提示，按提示继续核对。
