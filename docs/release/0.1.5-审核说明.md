# 0.1.5 审核说明

## 版本描述

> 新增左右拼接模式。用户可在首页选择上下或左右方向，选择 2–20 张同方向连续截图，在设备本地自动识别重复区域、微调接缝并生成长图或宽图。图片不上传服务器。

## 测试说明

> 无需登录。首页默认“上下拼接”；选择竖向连续截图可生成长图。切换为“左右拼接”后，选择横向连续截图可生成宽图。图片方向与所选模式不一致时会给出提示。完成后可预览并保存到相册。原图和结果仅在设备本地处理。

## 功能页面

`pages/index/index`

## 隐私与内容安全边界

- 沿用已生效的隐私声明：用户主动选择的照片或视频信息、相册（仅写入）。
- 未新增登录、账号、网络请求、上传、下载、WebSocket、第三方 SDK 或外部网页。
- 未新增用户内容发布、社区、评论、公开展示或用户拼接结果分享入口。
- 固定首页卡片分享仍只使用预设标题和预设封面，不读取用户原图或拼接结果。
- 功能仍属于本地图片处理，服务类目无需因横向拼接而变化。

## 提交审核前真机检查

- 在 iOS 和 Android 各验证一次上下拼接与左右拼接。
- 左右拼接至少验证 2 张、8 张、20 张横向连续截图。
- 验证自动接缝、手动微调、预览、保存相册与重新拼接。
- 验证选择错误方向图片时只提示，不崩溃、不上传。
- 使用全新隐私授权状态验证首次选图、拒绝后重试与保存相册。

本文件只提供审核填写与验证依据，不代表 0.1.5 已通过微信审核或已正式发布。
